# WispLib

WispLib 0.4.0 — библиотека эффектов для контент-паков VoxelCore 0.32. Обычные эффекты описываются в JSON и запускаются из Lua. В этой версии добавлено управление экранными GLSL-постэффектами через `vfx.screen`.

Руководства именно для 0.4.0 лежат рядом: [первый эффект](WispLib_Руководство_разработчика.md), [пример экранных GLSL-помех](WispLib_Руководство_разработчика.md#экранный-эффект-радиопомехи-реагирующие-на-движение) и [справочник API](WispLib_API_Manual.md). Онлайн-документация: [wisplib.mixai.fun](https://wisplib.mixai.fun/). Список изменений: [CHANGELOG.md](CHANGELOG.md).

Отдельный минимальный content pack, который показывает экранные помехи с реакцией на движение игрока: [пример и установка](examples/signal_interference/README.md).

## Что можно создавать

| Тип | Как работает | Ограничение |
|---|---|---|
| `billboard` | Плоские частицы штатной системы VoxelCore | Нельзя менять transform уже выпущенной частицы по отдельности. |
| `mesh` | Много управляемых 3D-элементов на одной Entity | Элементы делят одну Entity и не имеют отдельных физических тел. |
| `entity` | Отдельная игровая Entity для каждой частицы | Нагрузка растёт с числом Entity и их компонентов. |
| `vfx.screen` | GLSL шейдер обрабатывает изображение кадра | Это постобработка экрана, а не 3D-геометрия или система частиц. |

Для `billboard`, `mesh` и `entity` JSON задаёт эмиттеры, движение и события. Lua может запускать экземпляры, привязывать их к Entity и менять параметры. `vfx.world` сохраняет сериализуемое описание эффекта для повторного запуска после загрузки мира.

`vfx.screen` упрощает запуск и настройку шейдера: профиль задаёт слот и параметры, а Lua handle позволяет менять uniform-параметры и интенсивность, в том числе плавно. Сам GLSL-файл и слот всё равно объявляет контент-пак, который использует эффект.

WispLib использует API VoxelCore и не добавляет собственного renderer, GPU-симуляции частиц или сетевой репликации. Подробные ограничения экранных эффектов приведены в [справочнике API](WispLib_API_Manual.md#экранные-glsl-post-effects).

## Подключение

1. Скопируйте папку `wisplib` в каталог `content/` проекта и добавьте её в `base_packs` в `project.toml`.
2. Укажите зависимость `!wisplib@>=0.4.0` в `package.json` своего пака.
3. Начните с [руководства разработчика](WispLib_Руководство_разработчика.md), затем используйте [справочник API](WispLib_API_Manual.md).

Основная точка входа Lua:

```lua
local vfx = require "wisplib:vfx"
```

Основной runtime и API находятся в `content/wisplib/modules/vfx.lua`; экранные эффекты реализованы в `content/wisplib/modules/screenfx.lua`.
