# WispLib

WispLib — content pack с Lua API для эффектов в VoxelCore 0.32. Вы описываете эффект в JSON своего пака и запускаете его из игрового Lua-кода. Движок и файлы WispLib менять не требуется.

Полная документация, руководство и примеры: [wisplib.mixai.fun](https://wisplib.mixai.fun/).

Например, можно создать кольцо из 3D частиц, привязать его к Entity и менять положение частиц каждый update. Для обычных плоских частиц библиотека использует штатный `gfx.particles` VoxelCore.

## С чего начать

1. Положите папку `wisplib` в `content/` проекта и добавьте `wisplib` в `base_packs` файла `project.toml`.
2. Подключите зависимость `!wisplib@>=0.3.3` в `package.json` своего пака и включите его в `base_packs`.
3. Пройдите [руководство: первый эффект](WispLib_Руководство_разработчика.md). Там приведены готовые JSON и Lua файлы.

Lua API импортируется так:

```lua
local vfx = require "wisplib:vfx"
```

`vfx` — имя переменной в вашем скрипте. Основной вызов — `vfx.spawn("вашпак:имя_эффекта", options)`. Он возвращает handle конкретного экземпляра или `nil, ошибка`. Подробные методы и форматы — в [справочнике API](WispLib_API_Manual.md).

## Что библиотека умеет

| Способ | Что создаёт | Ключевое ограничение |
|---|---|---|
| `billboard` | Плоские частицы встроенного `gfx.particles` | Нельзя управлять каждой уже выпущенной частицей отдельно. |
| `mesh` | Управляемые 3D элементы на одной Entity с skeleton slots | У элементов нет собственной физики Entity. |
| `entity` | Отдельную Entity на каждую частицу | Стоимость растёт вместе с числом Entity и их компонентов. |

JSON definitions задают emitters, параметры, движение и события. Lua API позволяет привязывать эффект к Entity, задавать точки и траектории, регистрировать собственные формы и controllers. `vfx.world` хранит сериализуемое описание эффекта для повторного запуска после загрузки мира. WispLib также может запускать звуки через аудио API VoxelCore.

Сохраняемые WorldEffects записываются отдельно для каждого мира через `pack.data_file` в `world:data/wisplib/world_effects.json`. Старые файлы в `user:wisplib/` автоматически не импортируются; способ переноса описан в справочнике API.

WispLib не содержит собственного renderer или сетевой репликации. Результат прозрачности и освещения зависит от модели, материала и пути рендеринга VoxelCore.

## Где находится код

Публичный API и runtime: `content/wisplib/modules/vfx.lua`. Автоматическое обновление и сохранение: `content/wisplib/scripts/hud.lua` и `content/wisplib/scripts/world.lua`.
