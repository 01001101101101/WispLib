# История изменений WispLib

## 0.3.4

Исправления и надёжность runtime:

- Исправлен запуск дочернего эффекта из обработчика события.
- Поправлены позиции частиц и Entity при привязке эффекта к движущемуся anchor, в том числе с локальным смещением.
- Изменение количества Entity-частиц теперь учитывает режим выпуска по умолчанию.
- Конечные controlled mesh-эффекты корректно завершаются; завершённые частицы удаляются из runtime-списка.
- Для mesh-эффектов расширены границы видимости и сокращены повторные вычисления transform/config в течение update.
- Перед запуском billboard проверяются texture aliases; при отсутствующей текстуре API возвращает диагностическую ошибку.
- Сохранение WorldEffects использует два чередующихся файла с поколением и контрольной суммой. При повреждении новейшей копии библиотека пробует предыдущую; старый `world_effects.json` поддерживается при миграции.
- При некорректной записи или отсутствующем definition загрузка сообщает ошибку и не заменяет действующий набор WorldEffects.

Проверки включают headless runtime, client runtime и сохранение/загрузку WorldEffect между отдельными запусками VoxelCore.
